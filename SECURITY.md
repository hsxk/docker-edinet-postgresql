# Security Policy

## Supported version

Security fixes target the current `main` branch and the most recently
published image. Older immutable tags are historical releases.

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, database
contents, tokens, or private keys.

If GitHub offers **Security → Report a vulnerability** for this repository, use
that private channel. Otherwise open a minimal issue asking for a private
contact path without including sensitive details.

If the issue originates in PostgreSQL, PostGIS, Debian, Docker, or another
upstream dependency, report it upstream as appropriate as well. Please still
report image-specific impact here when this repository's packaging or
configuration changes exploitability.
